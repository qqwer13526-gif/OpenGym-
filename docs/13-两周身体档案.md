# 两周身体档案

更新日期：2026-11-02。桌面端入口：“我的” → 个人身体档案。

## 周期与数据
- 首次身体实测日期作为周期起点，每14天固定划分。已有身体记录自动参与展示；后续保存时将起点写入档案。
- 显示本周期是否更新、最近实测日期和下一次更新日期。进入新周期尚无实测时显示待更新，不编造身体状态。
- 可填写体重、体脂率与腰围，至少一项。体脂率需注明测量方法/设备；填写未完成的指标不做补零。
- 可提前记录或补录历史日期。每个实际日期一条综合记录，选择已有日期载入原值，保存后更新；其他日期保留。
- 周期汇总分别取各指标最后一次实测，并显示实际测量日期。体脂按所选同一方法/设备隔离。
- 首次建档后周期起点固定，删除单条记录不移动周期起点。

## 可视化与档案库
个人页顶部展示本周期体重、体脂率、腰围和较上周期变化。三张独立曲线显示最近26个周期，缺失周期不连线；单个数据点不制造趋势。体脂变化使用百分点。

周期汇总与完整原始身体记录表可查看、编辑、删除。更早记录仍保留在原始档案库与导出文件中。变化曲线是实测展示，不是预测值。

继续使用 monitoring 数据集，新增可选 waistCm 和 profile.bodyCycleStart 字段。旧版数据可读取，身体记录和恢复预测共享真实数据，避免两份相互矛盾的档案。恢复页面更新记录会保留已有腰围，删除身体实测会保留同日疲劳、酸痛与训练记录。

个人档案随原有“导出训练数据”备份；可通过导入恢复。目前存储在当前浏览器，不是云数据库。周期提示在打开页面时计算，不会后台发送通知。

## 验证
规则检查：首次记录、14天边界、同周期最后一次值、原始记录保留、体脂设备隔离、空周期、仅腰围记录、无效日期与数值。

浏览器检查：首次录入、体脂方法必填、保存与刷新、恢复页修改时保留腰围、同日编辑不重复、删除身体数据保留疲劳和周期起点、三张曲线、导出数据包含身体记录和起点、1280/1512/1920桌面无页面横向溢出。未发现未捕获浏览器错误。
