# 计划建议规则与数据说明

版本：2026-11-02。以下阈值是可调整的产品规则；不能当作对每个人都适用的生理分界线。

## 计划结构

- 全身目标：检查五个已收录区域是否有主要或协同参与的动作。腹部等尚未收录，因此不宣称覆盖全身全部肌肉。
- 当天同一动作模式达到3项时，提示可能精简，并列出实际组数；不直接判定训练过量。
- 预计用时：每次动作按3秒、组间休息按用户设置、动作切换按1分钟估算。不含热身，属于排程估计。
- 用户设置重点动作时，允许预览将其前置。力量目标下，孤立动作在复合动作前面时给出可选顺序提醒。
- 相邻训练日同一区域各安排至少6个主练组时，提示用户结合完成表现与恢复感受检查。6组不是恢复或安全分界线，也不据此诊断疲劳。

## 负重与进阶

- 计划重量留空就是未知，不按0公斤或某个推荐起始重量处理。
- 比较限定为同动作、同负重口径、同器械类型和相同组数与次数目标。器械动作还要求计划中明确的器械编号与记录一致。
- 最近两条可比记录必须来自不同日期，都完成计划组数和当前重量下的次数上限，而且最后一组自评不是“接近极限”，才提示可考虑进阶。
- 设置了最小加重档位时，可预览“当前重量＋该档位”；未设置时不编造加重公斤数。所有调整均需用户确认。
- 最近记录未达目标时，不跳过它们寻找更早的成功记录来触发进阶。
- 两个不同日期在当前重量都有组未达次数下限时，建议检查目标、负重和休息安排，不自动减重。
- 相同目标下计划重量比最近一次均匀负重记录高超过10%时，显示变化幅度供确认。10%为产品提示阈值，不是危险阈值；不同动作的公斤数不作横向比较。
- 自重动作的0公斤表示未加额外负重，不表示人体没有负荷。不同器械的标称公斤数不比较。

上述检查由本地规则计算，没有假装调用实时大模型，也没有把内置规则标为经过效果验证的个体化处方。用户经验字段仅作旧配置兼容保留，当前界面不收集未参与计算的经验信息。

## 统计

- 主练、协同和稳定分开计算。同一区域的多个主练肌肉，在同一训练组只统计一次。
- 周计划统计全部七天安排；本周完成统计按北京时间周一至今日的已记录实际训练组，次数大于0才计为完成组。
- 同一组可以涉及多个不同区域，各区域组数不能相加作为全身实际总组数。
- 计划撤回只恢复动作、目标和排程，实际训练记录保留。删除完成记录属于单独确认操作。
